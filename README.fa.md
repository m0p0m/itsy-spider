# 🕷 Itsy

**یک عنکبوت کوچولو با مغز واقعی که روی دسکتاپ شما زندگی می‌کند.**

روی پنجره‌هایتان راه می‌رود، از زیرشان با تار آویزان می‌شود، گوشه‌ی پنجره‌ها تار می‌تند، از موسی که به سمتش هجوم بیاورد فرار می‌کند، با موس آرام دوست می‌شود و موسی که بی‌حرکت مانده را شکار می‌کند.

[English](README.md) · **فارسی**

## ویژگی‌ها

- **مغز دارد:** ترس، گرسنگی، انرژی، کنجکاوی، حوصله‌سررفتن و **اعتماد به شما** (که بعد از بستن برنامه هم یادش می‌ماند). بر اساس حالش تصمیم می‌گیرد چه کار کند.
- **حس عنکبوتی:** اگر موس را سریع به سمتش ببرید، قبل از اینکه فکر کند جاخالی می‌دهد و فرار می‌کند.
- **دوستی:** اگر کنارش آرام باشید، کم‌کم اعتماد می‌کند، جلو می‌آید و برایتان دست تکان می‌دهد.
- **شکار:** اگر موس ۲۵ ثانیه تکان نخورد و گرسنه باشد، آرام نزدیک می‌شود، می‌پرد و دور موس تار می‌پیچد. برای آزاد شدن باید **کلیک کنید**: از ۳ تا ۱۰ کلیک، بسته به اینکه چقدر گرسنه است. اگر کلیک نکنید دوباره می‌پیچدش.
- **با پنجره‌های واقعی کار می‌کند:** روی لبه‌ی پنجره‌ها راه می‌رود و از زیرشان آویزان می‌شود. پنجره را بکشید تا تارها با آن جابه‌جا شوند. پنجره را ببندید تا تارش بریزد.
- **تارهای واقعی:** تار دایره‌ای با مارپیچ نرم و قطره‌های شبنم. با کشیدن سریع موس از رویشان پاره می‌شوند.
- **ظاهر سوپرعنکبوت:** قرمز و آبی براق با خطوط تار، سه‌بعدی با سایه. حالت پیکسلی هم دارد.

## روشن و خاموش کردن

| کار | روش |
|---|---|
| **روشن کردن** | دستور `npm start`، یا اگر با فایل نصبی نصب کرده‌اید از منوی Start برنامه‌ی *Itsy* را باز کنید |
| **حالت دمو** | دستور `npm run demo`: بعد از ۱۰ ثانیه شکار می‌کند، برای گرفتن ویدیو عالی است |
| **خاموش کردن** | روی آیکون 🕷 کنار ساعت راست‌کلیک ← **Quit**، یا دستور `npm run stop` |
| **مکث و ادامه** | آیکون کنار ساعت ← **Pause** (مخفی می‌شود ولی بسته نمی‌شود) |
| **اجرا همراه ویندوز** | آیکون کنار ساعت ← **Start with system** |
| **آزاد کردن فوری موس** | کلیدهای `Ctrl+Alt+X` |

## تنظیمات منوی کنار ساعت

| گزینه | کار |
|---|---|
| **Pause** | مخفی کردن عنکبوت |
| **Free my cursor** | آزاد کردن موس گیرافتاده |
| **Clear webs** | پاک کردن همه‌ی تارها |
| **Size** | اندازه: کوچک، متوسط، بزرگ |
| **Pixel style** | ظاهر پیکسلی |
| **Show its brain** | نمایش مغزش: الان چه می‌کند و چه حسی دارد (برای ویدیو عالی است) |

## رفع مشکل

| مشکل | راه‌حل |
|---|---|
| موسم در تار گیر کرده | سریع کلیک کنید یا `Ctrl+Alt+X` را بزنید. بعد از ۶۰ ثانیه هم خودش ولش می‌کند. |
| عنکبوت را نمی‌بینم | شاید پشت یک پنجره است یا روی Pause مانده. آیکون کنار ساعت را چک کنید یا **Size ← Large** را بزنید. |
| خیلی زود سراغ موس می‌آید | مقدار `idleToHunt` و `cooldown` را در فایل `src/renderer/app.js` بیشتر کنید. |
| `npm install` خیلی کند است | Electron حجیم است؛ با VPN یا اینترنت دیگری امتحان کنید. |
